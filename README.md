### ⚡ About Me

I am a **Senior Full-Stack & Generative AI Engineer** and **Technical Lead** at **Ikontel Solutions** based in Bangalore, India. I specialize in building mission-critical enterprise systems, low-latency voice automation pipelines, and high-concurrency cloud architectures for enterprise clients like **Swiggy** and **ITC**.

* 🔭 **Engineering Focus:** Real-time speech pipelines (Whisper STT + Silero VAD), custom LLM inference orchestration, and sub-second API microservices.
* 🚀 **Key Achievement:** Architected Swiggy's GenAI voice platform handling 50K–100K daily customer records and 1M+ calls.
* 💡 **UI/UX Philosophy:** Clean component modularity, micro-frontend independence, and responsive, fluid interfaces.
